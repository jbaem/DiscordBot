# 🤖 디스코드 방 관리 봇 (Discord Management Bot)

디스코드 서버의 **임시 음성 채널(Join-to-Create) 자동 생성 및 삭제**, **채널 정리 및 모더레이션**, **신규 멤버 환영/퇴장 알림 및 자동 역할 부여**를 담당하는 올인원 방 관리 봇입니다.

---

## 🔐 명령어 권한 구분

모든 명령어는 **한글 슬래시 명령어**로 제공되며 두 등급으로 나뉩니다. 관리자 전용 명령어는 권한이 없는 멤버의 명령어 목록에서 **숨겨지며**, 서버 설정에서 권한을 바꿔 노출되더라도 봇이 실행 전에 한 번 더 검사해 거부합니다.

| 등급 | 사용 조건 | 명령어 |
|---|---|---|
| 👑 **관리자 전용** | 서버 소유자, 관리자(Administrator) 권한, 또는 서버 관리(Manage Server) 권한 | `/채널연결`, `/테스트`, `/알림문구`, `/음성방설정`, `/음성방`, `/채널관리`, `/자동역할`, `/이모지역할`, `/백업`, `/핑` |
| 👥 **모든 멤버** | 제한 없음 (`/유저정보` 로 다른 유저를 조회하는 것은 관리자만 가능) | `/유저정보`, `/도움말` |

`/도움말` 은 사용자의 등급에 맞춰 사용할 수 있는 명령어만 보여 줍니다. 관리자 역할(예: `덩쿠림보`)에는 **서버 관리** 권한을 켜 두어야 관리자 명령어가 보입니다.

## 🌟 주요 기능

### 1. 🔗 채널 연결 (`/채널연결`)
기능별 채널을 한 명령어로 연결·해제합니다. 연결하지 않은 기능은 비활성화 상태입니다.
- `/채널연결 입장알림 <채널>` : 신규 멤버 환영 메시지를 보낼 텍스트 채널
- `/채널연결 퇴장알림 <채널>` : 멤버 퇴장 알림을 보낼 텍스트 채널
- `/채널연결 닉네임로그 <채널>` : 닉네임 변경 로그를 기록할 텍스트 채널
- `/채널연결 음성생성 <채널>` : 접속 시 개인 통화방이 생성되는 음성 채널 (Join-to-Create 트리거)
- `/채널연결 확인` : 연결된 채널 전체 확인
- `/채널연결 해제 <기능>` : 특정 기능의 채널 연결 해제(비활성화)
- 슬래시 명령어로 연결하지 않은 서버는 `.env` 의 `WELCOME_CHANNEL_ID`, `LEAVE_CHANNEL_ID`, `JOIN_TO_CREATE_CHANNEL_ID` 를 폴백으로 사용합니다.

### 2. 👋 멤버 입장 / 퇴장 알림
- `/알림문구 입장 <문구>` / `/알림문구 퇴장 <문구>` : 알림 문구 설정 (변수 지원: `{user}`, `{userName}`, `{userTag}`, `{userId}`, `{server}`, `{count}`, `{joinedAt}`, `{joinedAtRelative}`, `{createdAt}`, `{accountAge}`, `{joinCount}`, `{isRejoin}`)
- `/알림문구 확인` : 현재 문구와 미리보기 확인
- `/테스트 입장알림` / `/테스트 퇴장알림` : 연결된 채널로 실제와 같은 형태의 테스트 메시지 전송
- 알림 임베드에는 **입장 시각**(입장 알림) 또는 **퇴장 시각과 함께한 기간**(퇴장 알림)이 표시됩니다. 멤버 수를 넣고 싶으면 문구에 `{count}` 변수를 사용하세요.
- **재입장(들낙) 멤버 자동 감지**: 서버별 멤버 입장/퇴장 이력을 기록하여 재입장 시 알림의 제목과 색상을 구분해 표시
- **닉네임 변경 로그**: 닉네임 로그 채널을 연결하면 멤버가 서버 닉네임을 바꿀 때마다 **변경 시각, 변경 전 이름, 변경 후 이름, 유저 정보**를 임베드로 기록. 유저별 최근 변경 이력(최대 10건)은 `/유저정보` 에서도 확인 가능

### 3. 🔊 임시 음성방 자동 생성 (Join-to-Create)
- `/음성방설정 자동설정` : 전용 카테고리와 "➕ 클릭하여 통화방 생성" 채널을 **원클릭으로 자동 생성 및 연결**
- `/음성방설정 이름서식 <서식>` : 생성될 방 이름 서식 변경 (예: `🔊 {userName}의 통화방`)
- `/음성방설정 확인` : 설정 상태 확인 (생성 채널 연결/해제는 `/채널연결 음성생성`, `/채널연결 해제 음성생성`)
- 멤버가 생성 채널에 접속하면 **개인 음성방을 즉시 생성**하고 이동시키며, 마지막 멤버가 퇴장하면 **자동 삭제**됩니다.
- 방 제어 (자신이 만든 방에서만 동작):
  - `/음성방 이름 <이름>` : 방 이름 변경
  - `/음성방 인원 <인원수>` : 최대 인원 설정 (0: 무제한)
  - `/음성방 잠금` / `/음성방 잠금해제` : 다른 멤버 입장 차단 / 해제

### 4. 🛡️ 채널 관리 (`/채널관리`)
- `/채널관리 잠금 [사유]` / `/채널관리 잠금해제` : 현재 채널 잠금 / 해제
- `/채널관리 슬로우모드 <초>` : 슬로우 모드 설정 (0은 해제, 최대 6시간)
- `/채널관리 메시지삭제 <개수> [유저]` : 최근 메시지 최대 100개 일괄 삭제 (특정 유저만 골라 삭제 가능, 14일 이내 메시지)

### 5. 🎭 역할 자동화
- **자동 역할 (모든 구성원)** — 예: `포켓몬`
  - `/자동역할 설정 [이름]` : 구성원 역할을 새로 만들어 자동 역할로 지정하고, **기존 멤버 전체에게도 즉시 부여** (기본 이름: `포켓몬`)
  - `/자동역할 지정 <역할>` : 이미 있는 역할을 자동 역할로 지정
  - `/자동역할 일괄적용` : 현재 멤버(봇 제외) 전체에게 자동 역할 일괄 부여
  - `/자동역할 확인` / `/자동역할 해제` : 설정 확인 / 비활성화
  - 새 멤버가 들어오면 자동으로 부여됩니다. 슬래시 명령어로 설정하지 않은 서버는 `.env` 의 `AUTO_ROLE_ID` 를 사용합니다.
- **이모지 반응 역할 (원하는 사람만)** — 예: 🎲 `겜블러`
  - `/이모지역할 추가 <역할> <이모지> [설명]` : 이모지와 역할 연결 (유니코드 또는 서버 커스텀 이모지)
  - `/이모지역할 패널 [채널] [제목] [설명]` : 이모지를 누르는 패널 메시지 게시 (봇이 이모지를 미리 달아 둡니다)
  - 멤버가 패널의 **이모지를 누르면 역할이 부여되고, 반응을 해제하면 역할이 제거**됩니다.
  - `/이모지역할 목록` / `/이모지역할 제거 <역할>` / `/이모지역할 갱신` : 목록 확인 / 연결 해제 / 게시된 패널 갱신
  - 등록되지 않은 이모지 반응은 자동으로 정리되어 패널이 깔끔하게 유지됩니다.
- ⚠️ 두 기능 모두 **봇의 역할이 부여할 역할보다 위**에 있어야 하며, 관리자·서버 관리·@everyone 멘션 등 위험 권한이 있는 역할과 봇/연동 전용 역할은 등록할 수 없습니다.

### 6. 💾 설정 및 멤버 이력 백업 / 복원 (`/백업`)
- 봇은 설정과 멤버 이력, 활동 기록을 `data/` 폴더의 JSON 파일에 **자동 저장**합니다. 아래 명령어는 호스팅 장애나 인스턴스 삭제에 대비한 **수동 백업**용입니다.
- `/백업 내보내기` : 현재 서버의 설정(연결 채널, 문구, 역할 설정), 멤버 입장/퇴장·닉네임 이력, 활동 기록을 JSON 파일로 내려받기 (본인에게만 표시)
- `/백업 불러오기 <파일> [모드] [강제]` : 내려받은 백업 파일을 업로드해 복원
  - 모드 `병합`(기본): 기존 이력과 합치고 입장 횟수·포인트 등은 더 큰 값을 유지
  - 모드 `전체 교체`: 현재 이력을 지우고 백업 내용으로 덮어쓰기
  - 다른 서버에서 만든 백업은 `강제` 옵션을 켜야 적용되며, 현재 서버에 없는 채널 ID는 복원 후 안내됩니다.
- ⚠️ 백업 파일에는 채널 ID와 멤버 ID, 입장 이력이 포함되므로 외부에 공유하지 마세요.

### 7. 📊 유저 정보 및 활동 포인트
- `/유저정보` : **본인 정보를 DM으로** 받아 보기 (모든 멤버)
- `/유저정보 <유저>` : 다른 유저의 정보 조회 (**관리자 전용**, 관리자 본인에게만 표시)
  - 기본 정보: 이름(닉네임), 유저명, ID, 계정 생성일, 부스트 여부
  - 서버 기록: 서버 입장일, 함께한 기간, 입장 횟수(재입장 여부), 마지막 퇴장 시각, 최근 닉네임 변경
  - 활동: 포인트, 활동일 수, 메시지 수, 음성 채널 체류 시간, 마지막 활동 시각
  - 역할 목록
- 활동은 봇이 켜져 있는 동안 자동으로 집계되어 `data/activity.json` 에 저장됩니다. (메시지 내용은 저장하지 않으며 `MESSAGE CONTENT INTENT` 가 필요하지 않습니다.)
- 포인트 규칙 (`src/utils/activityManager.js` 상단 상수로 조정 가능):
  - 메시지 1개 = **1점** (60초 쿨다운, 도배 방지)
  - 음성 채널 1분 = **1점** (서버 AFK 채널 제외)
  - 활동일 = 메시지 또는 음성 활동이 있었던 날짜 수 (한국 시간 기준)

### 8. ⚙️ 유틸리티
- `/핑` : 봇 응답 속도(레이턴시) 및 웹소켓 핑 측정
- `/도움말` : 명령어 및 기능 안내서 확인

## 🛠️ 사전 준비 (디스코드 개발자 포털 설정)

봇을 구동하기 위해 디스코드 개발자 포털에서 봇을 등록해야 합니다.

### 1. 봇 생성 및 토큰 발급
1. [Discord Developer Portal](https://discord.com/developers/applications)에 접속하여 로그인합니다.
2. 우측 상단 **New Application** 클릭 후 이름을 지정하고 생성합니다.
3. 좌측 메뉴 **Bot** 클릭:
   - **Reset Token**을 눌러 봇 토큰을 복사합니다. (이 토큰이 `.env`의 `DISCORD_TOKEN`이 됩니다.)
   - ⚠️ **중요 (권한 허용)**: 스크롤을 내려 **Privileged Gateway Intents** 섹션에서 **SERVER MEMBERS INTENT** 스위치를 반드시 **ON**으로 켭니다. (환영 메시지 및 자동 역할을 위해 필수입니다.)

### 2. 애플리케이션 ID 확인
- 좌측 메뉴 **General Information**에서 **Application ID**를 복사합니다. (`.env`의 `CLIENT_ID`)

### 3. 디스코드에서 채널/서버/역할 ID 확인하는 법
1. 디스코드 앱 실행 -> **사용자 설정 (⚙️)** -> **고급** -> **개발자 모드**를 켭니다.
2. 이제 서버 이름, 텍스트 채널, 음성 채널, 역할을 **마우스 우클릭**하면 맨 아래에 **[ID 복사]** 버튼이 나타납니다.

### 4. 봇 서버에 초대하기
1. 좌측 메뉴 **OAuth2** -> **URL Generator** 클릭
2. **SCOPES**:
   - `bot`
   - `applications.commands` (슬래시 명령어 사용을 위해 필수)
3. **BOT PERMISSIONS**:
   - `Administrator` (가장 편리함) 또는 아래 권한 체크:
     - `Manage Channels` (채널 관리)
     - `Manage Roles` (역할 관리)
     - `Manage Messages` (메시지 관리)
     - `Move Members` (음성 채널 멤버 이동)
     - `Connect`, `Speak` (음성 접속/발언)
     - `Send Messages`, `Embed Links`, `Read Message History`
4. 하단에 생성된 URL을 복사하여 웹 브라우저 주소창에 넣고 자신의 서버에 초대합니다.

## ⚙️ 설정 파일 (.env) 작성

프로젝트 루트 폴더의 `.env` 파일을 열고 복사한 ID 값들을 입력합니다:

```env
# 필수 항목
DISCORD_TOKEN=여기에_봇_토큰_입력
CLIENT_ID=여기에_애플리케이션_ID_입력

# 개발/테스트용 서버 ID (입력 시 해당 서버에 슬래시 명령어가 즉시 동기화됩니다)
GUILD_ID=123456789012345678

# [기능 1] 개인 음성방 자동 생성용 트리거 채널 ID
# (음성 채널을 만들고 '🔊 개인방 생성' 등으로 이름 붙인 후 우클릭하여 ID 복사)
JOIN_TO_CREATE_CHANNEL_ID=

# [기능 2] 입장 및 퇴장 알림 채널 ID
WELCOME_CHANNEL_ID=
LEAVE_CHANNEL_ID=

# [기능 3] 신규 멤버 자동 지급 역할 ID (선택 사항)
# 서버에서 /autorole 명령어로 설정하면 이 값보다 우선합니다.
# ⚠️ 봇의 역할 순위가 지급할 역할보다 위에 있어야 정상 작동합니다.
AUTO_ROLE_ID=
```
